A single-line resignation letter from a professional mourner who has wept at 400 strangers' funerals and finally noticed that nobody — not even the buffet — ever wept at his. One line, one job, one joke that lands on the last three words.

## Run

```sh
node main.ts
```

This writes the resignation line to `/output/entry.txt`.
